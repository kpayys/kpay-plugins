# 超级支付系统 × KPay

在[超级支付系统](https://paypro.com.cn)里把 KPay 加成一个直连渠道：支持支付宝、微信支付、云闪付，也支持在超级支付后台退款和查单。

- 适用版本：超级支付 2.x（PHP 8.2）
- 安装包：`kpay-superpay.zip`

## 开始前

按 [KPay 准备](../docs/kpay-setup.md) 拿到商户ID和 EPay Key。创建 EPay 密钥时，**授权域名**填超级支付的站点域名。

## 1. 上传接口文件

把 `Kpay.php` 上传到超级支付的支付接口目录：

```
网站根目录/
└── php/app/payApi/controller/
    └── Kpay.php          ← 文件名和类名都是 Kpay，不要改
```

## 2. 新增支付渠道

1. 后台 **支付渠道 → 直连渠道**，勾选 **开发者模式**，出现 **新增** 按钮。
2. 点 **新增**：

   | 字段 | 填什么 |
   |---|---|
   | 渠道名称 | `KPay 凯付`（随意） |
   | 接口编码 | `Kpay`（必须和文件名一致，K 大写） |
   | 显示名称 | 付款人看到的名字，比如「支付宝」 |
   | 支付方式 | 支付宝 / 微信 / 银联，和下一步账号里选的支付方式保持一致 |
   | 适用终端 | PC 和移动端都勾上 |

## 3. 添加渠道账号

在渠道列表点 **添加账号**：

| 配置项 | 填什么 |
|---|---|
| 接口地址 | `https://api.kaipay.cn/` |
| 商户ID | KPay「EPay 接入 → EPay 配置」里的商户 ID |
| 商户密钥 | 创建 EPay 兼容密钥时显示的 EPay Key |
| 支付方式 | 支付宝 / 微信支付 / 云闪付；选「KPay 收银台」则由付款人在 KPay 页面自己选 |
| 退款 API Key / Secret | 选填。填了才能在超级支付后台退款，见 [KPay 准备](../docs/kpay-setup.md#可选退款用的-api-key) |

保存后把账号设为启用。

## 4. 设置费率并测试

1. **支付渠道 → 费率分组**，给这个渠道设置费率，确认商户所在分组包含它。
2. 登录一个商户，用收银台测试付一笔小额，订单变成「已支付」就成功了。

## 服务商模式

给每个下级商户各添加一个渠道账号，填他自己的 KPay 商户ID和 EPay Key；再按超级支付的渠道账号分配规则，把商户指到对应账号。下级商户的 EPay 密钥授权域名同样要填超级支付的站点域名，并完成域名验证（验证文件里可以一行放一个商户的验证码）。

## 常见问题

**支付时提示「没有可用的支付渠道」**
渠道账号没启用、费率分组没包含这个渠道，或者商户不在这个分组里。

**付款成功但订单没变**
在订单详情的日志里看有没有收到 KPay 通知、验签是否通过；确认站点能被外网访问。

更多问题见 [常见问题](../docs/faq.md)。
