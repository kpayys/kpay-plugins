# WooCommerce × KPay

WordPress + WooCommerce 店铺用 KPay 收款：结账后跳到 KPay 付款页，手机和电脑自动匹配付款方式。支持经典结账和区块结账，兼容 HPOS，支持在订单页退款。

- 适用版本：WordPress 6.0+，WooCommerce 7.0+，PHP 7.4+
- 安装包：`kpay-for-woocommerce.zip`
- 店铺货币必须是人民币（CNY）

## 开始前

按 [KPay 准备](../docs/kpay-setup.md) 拿到商户ID和 EPay Key。创建 EPay 密钥时，**授权域名**填店铺的域名（WordPress「设置 → 常规」里站点地址的域名）。

## 1. 安装插件

二选一：

- 后台 **插件 → 安装插件 → 上传插件**，选择 `kpay-for-woocommerce.zip`，安装后启用。
- 或者把 `kpay-for-woocommerce` 文件夹上传到 `wp-content/plugins/`，再到插件列表启用。

## 2. 填写配置

**WooCommerce → 设置 → 付款**，找到 **KPay 凯付**，点 **管理**：

| 配置项 | 填什么 |
|---|---|
| 启用 | 勾选 |
| 显示名称 | 结账页上的付款方式名称，比如「支付宝 / 微信支付」 |
| 说明 | 结账页上的说明文字 |
| 接口地址 | `https://api.kaipay.cn/` |
| 商户ID | KPay「EPay 接入 → EPay 配置」里的商户 ID |
| 商户密钥 | 创建 EPay 兼容密钥时显示的 EPay Key |
| 支付方式 | 默认「KPay 收银台」，付款人自己选；也可以固定为支付宝 / 微信 / 云闪付 |
| 退款 API Key / Secret | 选填，填了才能在订单页退款 |

设置页顶部会显示异步通知地址（`https://你的店铺/wc-api/kpay/`），自动使用，不用填到任何地方。

**货币**：**WooCommerce → 设置 → 常规 → 货币** 要选人民币（¥）。不是人民币时结账页不会显示 KPay，设置页会给出提醒。

## 3. 测试

前台下一单，结账时选 KPay，付款完成后回到店铺，订单状态会变成「处理中」（虚拟商品可能直接「已完成」），订单备注里有 KPay 平台订单号。

## 退款

配置了退款 API Key 的，在订单详情点 **退款**，填金额后选「通过 KPay 凯付退款」。没配置的，到 KPay 商户后台退款，再在订单里手动记录退款。

## 常见问题

**结账页看不到 KPay**
检查：插件已启用、设置里勾选了启用、填了商户ID和密钥、店铺货币是人民币。

**付款成功但订单还是「待付款」**
在订单备注里看有没有 KPay 的记录。没有的话通知没到：检查站点能否被外网访问，安全插件或防火墙有没有拦 `/wc-api/kpay/`；没开固定链接时通知地址是 `/?wc-api=kpay`，同样要放行。

更多问题见 [常见问题](../docs/faq.md)。
