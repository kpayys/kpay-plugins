# 彩虹易支付 × KPay

两种用法，按需选：

| 用法 | 适合谁 | 要装什么 |
|---|---|---|
| [通道收款](#通道收款) | 把 KPay 接成易支付的上游通道，用你自己的 KPay 商户收款 | `plugins/kpay/` |
| [服务商模式](#服务商模式) | 你是 KPay 服务商，给易支付里的下级商户各自开 KPay 商户，钱直接进商户自己的账户 | 整个安装包 |

- 适用版本：彩虹易支付及同源二开程序（插件目录 `plugins/`、有「自定义子通道」功能的版本）
- 安装包：`kpay-epay.zip`，按网站根目录结构打包，直接解压到易支付根目录：

```
易支付根目录/
├── plugins/kpay/          通道插件 + 服务商模块（目录名必须是 kpay）
├── admin/kpay.php         后台：KPay 服务商
├── admin/ajax_kpay.php
├── user/kpay.php          商户中心：商户进件
└── user/ajax_kpay.php
```

> 易支付自带的 epay 插件也能直接对接 KPay（接口地址填 `https://api.kaipay.cn/`）。本插件多了：云闪付（`bank`）正确映射、在易支付后台直接退款、服务商进件。

## 通道收款

### 开始前

按 [KPay 准备](../docs/kpay-setup.md) 拿到商户ID和 EPay Key。创建 EPay 密钥时，**授权域名**填易支付的域名；后台 **系统设置 → 网站信息配置** 里填了「回调专用网址」的，填那个网址的域名。

### 步骤

1. 上传 `plugins/kpay/` 到易支付根目录。
2. 后台 **支付接口 → 支付插件**，点 **刷新插件列表**，看到 **KPay 凯付** 就装好了。
3. **支付接口 → 支付通道 → 新增**：
   - 支付方式：支付宝 / 微信 / 云闪付（调用值 `alipay` / `wxpay` / `bank`）
   - 支付插件：**KPay 凯付**
   - 其他（费率、限额）按需填写
4. 在通道列表点 **配置密钥**：

   | 配置项 | 填什么 |
   |---|---|
   | 接口地址 | `https://api.kaipay.cn/` |
   | 商户ID | KPay「EPay 接入 → EPay 配置」里的商户 ID |
   | 商户密钥 | 创建 EPay 兼容密钥时显示的 EPay Key |
   | 下单方式 | 「跳转 KPay 付款页」：浏览器直接跳到 KPay；「服务端下单」：易支付先向 KPay 下单，失败能看到原因。商户用 `mapi.php` 下单时总是服务端下单 |
   | 退款 API Key / Secret | 选填，见 [退款](#退款) |

5. 启用通道，在通道列表点 **测试**，付一笔小额，确认订单变成已支付。

### 退款

想在易支付订单列表里直接退款：到 KPay「API 密钥」创建一把「平台 API」密钥，勾选 **发起退款** 权限（授权域名同样要验证），把 API Key 和 API Secret 填到通道的「退款 API Key / Secret」。不填的话，到 KPay 商户后台退款。

## 服务商模式

整体流程：

```
下级商户在易支付提交进件 ──► KPay 审核 ──► 服务商发开通链接 ──► 商户开通 KPay 账户
      ──► 商户建 EPay 密钥并验证本站域名 ──► 在易支付绑定 ──► 自动生成子通道，开始收款
```

每个下级商户的钱直接进他自己的 KPay 账户，你在 KPay 服务商工作台拿分润。商户的证件、银行卡资料只保存在 KPay，易支付只记进件单号、状态和绑定的商户ID。

### 一、准备模板通道

1. 按 [通道收款](#步骤) 的第 1~3 步新建 KPay 通道（支付宝、微信各一个）。
2. **配置密钥** 时：
   - 接口地址：`https://api.kaipay.cn/`
   - 商户ID：填 `[appid]`
   - 商户密钥：填 `[appkey]`
   - 需要后台退款的，退款 API Key / Secret 填 `[appmchid]` / `[appsecret]`

   带方括号的是占位符，每个商户的子通道会用自己的值替换。这种通道自己不能收款。
3. **商户管理 → 用户组设置**，编辑商户所在的组：把支付宝、微信两行的通道都选为 **用户自定义子通道**。这样组内商户下单时，会走他自己绑定的子通道。

### 二、配置服务商模块

1. 用服务商账号到 KPay「API 密钥」创建「平台 API」密钥：
   - 接口权限勾选：创建进件单、查询进件单、上传进件材料、查询旗下商户、查询分润流水、查询费率调整、提交费率调整、查看旗下商户投诉
   - 授权域名：易支付的域名，并完成验证
2. 打开 `https://你的易支付/admin/kpay.php`，切到 **设置**：

   | 配置项 | 填什么 |
   |---|---|
   | 接口地址 | `https://api.kaipay.cn/` |
   | API Key / Secret | 上一步创建的密钥 |
   | 进件机构 | 先点 **测试连接并读取可用机构**，再勾选要提交的机构 |
   | 套餐 | 选填，按 KPay 给你开的套餐选 |
   | 回调通道 | 选一个 KPay 通道。KPay 会把进件状态推送到 `https://你的易支付/pay/applynotify/通道ID/`，页面上会显示完整地址 |
   | 绑定通道 | 勾选第一步的模板通道。商户绑定时为这些通道生成子通道 |
   | 商户自助 | 「允许商户在商户中心自己填写进件」「允许商户审核通过后自己绑定收款账户」，按需勾选 |
   | 建单附加参数 | 选填，JSON，原样合并进建单请求，比如 `{"fuyouConfigId":12}` 指定机构账号 |

   保存时如果提示「商户ID要填 [appid]」，说明模板通道的占位符没填对，回第一步检查。
3. 易支付菜单里不会自动出现这两个页面，建议把链接加到菜单或书签：
   - 后台：`/admin/kpay.php`
   - 商户中心：`/user/kpay.php`

   想加到菜单，可以在 `admin/head.php` 的「支付接口」下拉里加一行 `<li><a href="./kpay.php">KPay 服务商</a></li>`，在 `user/head.php` 的导航里加 `<li><a href="./kpay.php">商户进件</a></li>`。

### 三、下级商户进件

- **商户自己填**：商户登录易支付，打开 `/user/kpay.php`。
- **你代填**：后台 `/admin/kpay.php` → **进件单**，右上角输入商户 UID，点 **代商户进件**。

表单依次是：

1. 基本信息：主体类型、商户名称、联系人手机、经营类目、经营地区、详细地址。先点 **保存资料**。
2. 资料照片：保存后才能上传。身份证、银行卡、营业执照上传后会自动识别并回填姓名、证件号、卡号等。
3. 结算账户：填卡号后可以点 **识别开户行** 自动补全支行和联行号。
4. 页面上方会列出还缺的资料；都补齐后出现 **提交审核** 按钮。

提交后可以点 **刷新状态**。审核结果 KPay 会主动推送，被退回时页面显示原因，修改后再次提交。

### 四、审核通过后开通和绑定

1. **发开通链接**（服务商做）：
   - 让商户先在 KPay 注册账号，把他的 KPay 用户ID告诉你（就是他「EPay 配置」页的商户 ID）。
   - 在 KPay「进件与代理 → 聚合进件工作台」打开这张进件单（单号在易支付进件单列表里能看到），点 **生成完成开通链接**，目标用户ID填商户的用户ID，把链接发给商户。
   - 商户登录 KPay 后打开链接，完成开通。
2. **建 EPay 密钥并验证本站域名**（商户做）：
   - 商户在自己的 KPay「API 密钥」页创建「EPay 兼容 API」密钥，**授权域名填易支付的域名**，复制只显示一次的 EPay Key。
   - KPay 会给出一行 `kpay-domain-verification=...` 验证码。商户在易支付 `/user/kpay.php` 的 **绑定收款账户** 里粘贴，点 **写入**（你也可以在后台进件详情里替他写入）。模块会把这一行追加到易支付根目录的 `kpay-domain-verification.txt`，多个商户的验证码各占一行，互不影响。
   - 回 KPay 点验证，等状态变成已通过。
3. **绑定**：填入商户ID和 EPay Key，点 **绑定**。模块先向 KPay 校验这组凭据，通过后为每个绑定通道生成子通道，之后这个商户的订单就用他自己的 KPay 账户收款。

易支付根目录不可写时，写入验证码会失败，按提示手动把那一行加进 `kpay-domain-verification.txt` 即可。

### 五、日常运营

`/admin/kpay.php` 的其他几页直接读取 KPay 服务商接口：

| 页面 | 能看什么、做什么 |
|---|---|
| 进件单 | 所有进件单、状态、是否已绑定；详情里看各机构审核结果、同步状态、代提交、写入验证码、绑定 |
| 旗下商户 | 服务费率、本月交易额和分润、经营状态，可以筛出本月没交易或长期沉睡的商户 |
| 分润流水 | 每笔分润入账和冲正，页面顶部有累计和本月分润 |
| 费率调整 | 在「旗下商户」点 **调费率** 提交申请；这里看结果，待处理的可以撤回 |
| 商户投诉 | 旗下商户收到的投诉概况，提醒商户及时处理 |

## 常见问题

**保存设置提示「API密钥验证失败」**
API Key / Secret 不配对，或者没勾选需要的权限；这把 API Key 设了 IP 白名单的话，把易支付服务器的出口 IP 加进去。

**商户下单提示「KPay 商户ID或商户密钥未配置」**
订单走到了模板通道本身，而不是商户的子通道：检查用户组里是否设为「用户自定义子通道」，以及这个商户是否已经绑定。

**进件状态一直不变**
检查设置里的回调通道，确认 `https://你的易支付/pay/applynotify/通道ID/` 能被外网访问；也可以随时在进件详情里点 **同步机构状态**。

更多问题见 [常见问题](../docs/faq.md)。

## 升级和卸载

- 升级：覆盖上传新版文件，设置和进件记录都保留。
- 卸载：先停用 KPay 通道，再删除 `plugins/kpay/`、`admin/kpay.php`、`admin/ajax_kpay.php`、`user/kpay.php`、`user/ajax_kpay.php`。数据库里的 `pre_kpay_apply` 表和 `pre_config` 里 `kpay_sp` 开头的配置可以手动清理。
