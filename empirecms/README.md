# 帝国CMS × KPay

帝国CMS 的「在线支付」加一个 KPay 接口：会员购买点数、存预付款、购买会员组、商城订单都能用支付宝、微信支付、云闪付付款。

- 适用版本：帝国CMS 7.5 / 8.0 **UTF-8 版**
- 安装包：`kpay-empirecms.zip`

## 开始前

按 [KPay 准备](../docs/kpay-setup.md) 拿到商户ID和 EPay Key。创建 EPay 密钥时，**授权域名**填帝国CMS 的网站域名（后台「系统参数设置」里网站地址的域名）。

## 1. 上传文件

解压到网站根目录，得到：

```
网站根目录/
└── e/payapi/kpay/
    ├── to_pay.php     发起支付
    ├── payend.php     付款后跳回，在这里入账
    ├── notify.php     接收 KPay 异步通知
    └── kpay_lib.php
```

## 2. 添加支付接口

1. 打开压缩包里的 `install.sql`。表前缀不是默认 `phome_` 的，先把里面的 `phome_` 改成你的前缀。
2. 后台 **系统 → 备份与恢复数据 → 执行SQL语句**，粘贴执行。
3. 后台 **在线支付 → 管理支付接口**，编辑 **KPay 凯付**：

   | 字段 | 填什么 |
   |---|---|
   | 商户号 | KPay「EPay 接入 → EPay 配置」里的商户 ID |
   | 密钥 | 创建 EPay 兼容密钥时显示的 EPay Key |
   | 支付宝账号 | 留空（填了会被当作接口地址使用，一般不用改） |
   | 是否开启 | 开启 |

## 3. 测试

前台登录会员，进入在线充值，选 **KPay 凯付** 付一笔小额，付款后自动跳回网站并到账即可。

## 重要：入账发生在「付款后跳回」这一步

帝国CMS 把充值类型、商城订单号和登录会员存在付款人浏览器的 Cookie 里，服务器之间的异步通知拿不到这些信息，所以入账只能在付款人付完款**跳回网站**时完成（帝国CMS 自带的支付宝接口也是这样）。这意味着：

- 付款人需要在**发起支付的同一个浏览器**里完成付款并等待跳回；
- 付款后没有跳回（比如手机上付完直接关掉页面）时，钱已经到 KPay，但网站不会自动入账。到 KPay 商户后台找到这笔订单，在帝国CMS 后台手动给会员加点数或改订单状态即可；
- 插件在跳回时会核对订单号必须和本浏览器发起的一致，别人的跳转链接不能拿来给自己入账；同一笔 KPay 订单只会入账一次。

## 常见问题

**跳回后提示「订单信息不一致」**
付款时换了浏览器，或者浏览器禁用了 Cookie。按上面的方法在后台手动处理。

**页面乱码**
本插件适用于 UTF-8 版帝国CMS；GBK 版需要把 `e/payapi/kpay/` 下的文件转成 GBK 编码。

更多问题见 [常见问题](../docs/faq.md)。
