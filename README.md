# KPay 对接插件

把 [KPay 凯付](https://kaipay.cn) 接进常见的发卡、聚合支付系统。插件免费、开源，直接下载使用。

| 目录 | 适用系统 | 能做什么 |
|---|---|---|
| [`acg-faka/`](acg-faka) | 异次元发卡（acg-faka） | 商品下单、余额充值用 KPay 收款 |
| [`epay/`](epay) | 彩虹易支付及同源程序 | KPay 通道插件；服务商模块：下级商户进件、绑定收款、分润、费率调整、投诉查看 |
| [`superpay/`](superpay) | [超级支付系统](https://paypro.com.cn) | KPay 支付接口，支持退款、查单 |

支持的支付方式：支付宝、微信支付、云闪付。

下载：到 [Releases](../../releases) 下载对应的 zip，或者直接克隆本仓库复制目录。

## 准备工作

1. 在 KPay 开通商户，登录商户后台，打开 **EPay 配置** 页面，记下 **商户ID** 和 **密钥**。
2. 如果在「API 密钥」里给这把 EPay 密钥设置了 IP 白名单或授权域名，把你服务器的出口 IP、站点域名加进去。设了 IP 白名单时，下单方式要选服务端下单：浏览器表单提交时请求来自付款人的网络，过不了白名单。
3. 你的站点需要能被公网访问，KPay 才能把支付结果通知过来。

接口地址统一填 `https://api.kaipay.cn`。

## 异次元发卡

支持 3.x 版本，3.5.9 及以后版本的「多套支付配置」也能用。

1. 把 `acg-faka/KPay` 目录上传到网站的 `app/Pay/` 下，最终路径是 `app/Pay/KPay/Impl/Pay.php`。
2. 后台 **支付插件** 里找到 **KPay 凯付**，点 **配置**：

   | 配置项 | 填什么 |
   |---|---|
   | 接口地址 | `https://api.kaipay.cn`（默认已填） |
   | 商户ID / 商户密钥 | EPay 配置里的商户ID和密钥 |
   | 下单方式 | 默认「服务端下单后跳转」；服务器访问不了外网时改成「浏览器表单提交」 |
   | 订单标题 | 选填，付款页和付款人账单上显示的名称，`{tradeNo}` 会替换成订单号 |

3. 后台 **支付接口** 新增接口，插件选 **KPay 凯付**，通道编码填 `alipay`（支付宝）、`wxpay`（微信）、`unionpay`（云闪付）或 `cashier`（打开 KPay 收银台让付款人自己选）。
4. 用后台的「拨测」下一笔单，能打开付款页就说明配置正确。

回调地址由异次元发卡自动生成，不用手动填写。插件会校验签名、商户ID 和金额，三项都对上才会发货。

## 彩虹易支付

`kpay-epay.zip` 按网站根目录的结构打包，直接解压到易支付根目录：

```
plugins/kpay/        通道插件 + 服务商模块
admin/kpay.php       后台：KPay 服务商（进件单、旗下商户、分润、费率、投诉、设置）
admin/ajax_kpay.php
user/kpay.php        商户中心：商户进件
user/ajax_kpay.php
```

只用通道收款的话，上传 `plugins/kpay/` 就够了。

### 通道收款

1. 后台 **支付接口 → 支付插件**，点 **刷新插件列表**，能看到 **KPay 凯付** 就装好了。
2. **支付接口 → 支付通道** 新增通道：支付方式选支付宝 / 微信 / 云闪付（`alipay` / `wxpay` / `bank`），支付插件选 **KPay 凯付**。
3. 点通道的 **配置密钥**：

   | 配置项 | 填什么 |
   |---|---|
   | 接口地址 | `https://api.kaipay.cn/` |
   | 商户ID / 商户密钥 | EPay 配置里的商户ID和密钥 |
   | 下单方式 | 「跳转 KPay 付款页」或「服务端下单」。通过 `mapi.php` 下单的商户始终走服务端下单 |
   | 退款 API Key / Secret | 选填。想在易支付后台直接退款时，到 KPay「API 密钥」创建一把勾选了 **订单退款** 权限的 Key 填进来 |

4. 保存、启用通道，用后台的测试支付下一笔单。

### 服务商模式

你是 KPay 服务商、要给易支付里的下级商户各自开 KPay 商户时用这一套。每个下级商户的钱直接进他自己的 KPay 账户，你在 KPay 拿分润。

**一、准备通道**

1. 按上面的步骤建 KPay 通道，**配置密钥** 时商户ID填 `[appid]`、商户密钥填 `[appkey]`（需要后台退款再把退款 API Key / Secret 填成 `[appmchid]` / `[appsecret]`）。这样的通道自己不收款，只给各商户的子通道当模板。
2. **用户组** 里把对应支付方式设为 **用户自定义子通道**，并勾选这个 KPay 通道。

**二、配置服务商模块**

打开 `https://你的易支付/admin/kpay.php`，进入 **设置**：

| 配置项 | 说明 |
|---|---|
| API Key / Secret | 在 KPay 服务商工作台「API 密钥」创建，勾选进件（`onboarding:*`）和服务商（`sp:*`）权限 |
| 进件机构 | 点「测试连接并读取可用机构」后勾选，商户的进件会提交到这些机构 |
| 套餐 | 选填，按 KPay 给你的套餐选择 |
| 回调通道 | 选一个 KPay 通道，KPay 会把进件状态推送到 `https://你的易支付/pay/applynotify/<通道ID>/` |
| 绑定通道 | 第一步准备的通道；商户绑定收款账户时，模块为这些通道生成子通道 |
| 商户自助 | 打开后商户可以在商户中心 `/user/kpay.php` 自己填资料、自己绑定 |
| 建单附加参数 | 选填，JSON，原样合并进建单请求，比如指定机构账号或费率 |

**三、进件到收款**

1. 商户在 `/user/kpay.php` 填资料、传照片、提交审核；也可以在后台 **进件单** 里输入商户 UID 代他填写。身份证、银行卡、营业执照上传后会自动识别回填。
2. 审核状态由 KPay 推送，也可以在后台点「同步机构状态」。退回时商户能看到原因并修改后重新提交。
3. 审核通过后，到 KPay 服务商工作台为这张进件单生成开通链接发给商户。商户开通后，把他在 KPay「EPay 配置」里的商户ID和密钥填到 **绑定收款账户**（后台进件详情里，或开启自助后由商户自己填），模块校验通过后自动生成子通道，之后这个商户的订单就走他自己的 KPay 账户。

**四、日常运营**

后台其余几页直接读 KPay 服务商接口：

- **旗下商户**：服务费率、本月交易额和分润、经营状态（可筛选沉睡商户）
- **分润流水**：分润入账和冲正，带累计 / 本月汇总
- **费率调整**：给商户提交调价申请、查看结果、撤回待处理的申请
- **商户投诉**：旗下商户收到的平台投诉概况，提醒商户及时处理

商户资料只保存在 KPay；易支付本地只记进件单号、状态和绑定的商户ID。

易支付后台和商户中心的菜单不会自动出现这两个页面，可以把地址加到浏览器书签，或者自己在 `admin/head.php`、`user/head.php` 的菜单里加一行链接。

## 超级支付系统

适用于超级支付 2.x（PHP 8.2）。

1. 把 `superpay/php/app/payApi/controller/Kpay.php` 上传到网站的 `php/app/payApi/controller/` 下。
2. 后台 **支付渠道 → 直连渠道**，勾选 **开发者模式**，点 **新增**：接口编码填 `Kpay`，支付方式、适用终端按需选择。
3. 在渠道里 **添加账号**：

   | 配置项 | 填什么 |
   |---|---|
   | 接口地址 | `https://api.kaipay.cn/` |
   | 商户ID / 商户密钥 | EPay 配置里的商户ID和密钥 |
   | 支付方式 | 支付宝 / 微信支付 / 云闪付，或 KPay 收银台（付款人自选） |
   | 退款 API Key / Secret | 选填，填了才能在超级支付后台退款 |

4. 在 **费率分组** 里给这个渠道设置费率，用收银台测试一笔。

服务商模式下，给每个下级商户各添加一个渠道账号，填他自己的 KPay 商户ID和密钥，再按超级支付的渠道账号分配规则把商户指到对应账号。

## 常见问题

**提示签名错误？**
先确认商户ID、密钥没有多余空格。如果之前用的是其他通用易支付插件，换成本仓库的插件：KPay 不接受 `clientip`、`param` 这类扩展参数，通用插件带上它们会导致签名对不上。

**付款成功了但订单没变成已支付？**
- 站点要能被公网访问，防火墙、CDN 不要拦截 KPay 的通知请求。
- KPay 商户后台的订单详情里能看到通知结果；KPay 会对同一笔通知重试，处理成功后插件会返回 `success`。

**下单提示通知地址或跳转地址的域名不被允许？**
你给 EPay 密钥设置了授权域名。到 KPay「API 密钥」页面，把站点域名加进这把密钥的授权域名。

**金额对不上？**
插件只在通知里的金额与订单金额一致时入账。开了附加服务费或优惠券时，通知里的 `money` 仍是下单金额，付款人实付见 `payable_amount`。

**易支付服务商模块提示「API密钥验证失败」？**
检查 API Key / Secret 是否配对、权限是否勾选；API Key 设了 IP 白名单的话，把易支付服务器的出口 IP 加进去。
