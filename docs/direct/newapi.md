# NewAPI × KPay

NewAPI 自带易支付充值，直接填 KPay 的参数就能用，不用装插件。基于 NewAPI 的分支（如 Veloera）界面基本一致，按同样方法填写。

## 开始前

按 [KPay 准备](../kpay-setup.md) 拿到商户ID和 EPay Key。创建 EPay 密钥时，**授权域名**填 NewAPI 的访问域名（和下面「回调地址」是同一个域名）。

## 配置

1. 用管理员登录 NewAPI，打开 **系统设置 → 支付网关**（旧版界面在 **系统设置 → 支付设置**）。
2. **Epay 网关** 一栏：

   | 字段 | 填什么 |
   |---|---|
   | Epay 端点 / 支付地址 | `https://api.kaipay.cn/epay/` |
   | 回调地址 | NewAPI 自己的访问地址，比如 `https://ai.example.com`（KPay 会把支付结果通知到这个域名） |
   | 易支付商户 ID | KPay「EPay 接入 → EPay 配置」里的商户 ID |
   | Epay 密钥 | 创建 EPay 兼容密钥时显示的 EPay Key |

3. **付款方式** 里保留支付宝（`alipay`）、微信（`wxpay`）即可；想加云闪付，类型填 `unionpay`。
4. 保存，按需设置最低充值金额和充值倍率。

## 测试

用普通用户在 **钱包 / 充值** 页充一笔小额，付款后余额自动增加即可。

## 常见问题

- **充值后余额没到账**：检查「回调地址」是否能被外网访问，并且它的域名在 KPay 密钥的授权域名里、已验证通过。
- **提示回调地址校验失败**：同上，授权域名和回调地址的域名不一致。

更多见 [常见问题](../faq.md)。
