# 独角数卡 × KPay

独角数卡（dujiaoka）自带「易支付」支付通道，直接填 KPay 的参数就能用，不用装插件。

## 开始前

按 [KPay 准备](../kpay-setup.md) 拿到商户ID和 EPay Key。创建 EPay 密钥时，**授权域名**填独角数卡的域名（`.env` 里 `APP_URL` 的域名）。

## 配置

1. 后台 **支付通道**（部分版本叫「支付配置」），编辑自带的「易支付-支付宝」（没有就新增一条）。
2. 填写：

   | 字段 | 填什么 |
   |---|---|
   | 支付名称 | 用户看到的名字，比如「支付宝」 |
   | 支付标识 | `alipay`（微信那条填 `wxpay`） |
   | 支付场景 | 通用 |
   | 支付方式 | 跳转 |
   | 商户 ID | KPay「EPay 接入 → EPay 配置」里的商户 ID |
   | 商户 KEY | `https://api.kaipay.cn/submit.php`（**这里填的是完整的提交地址**，不是密钥） |
   | 商户密钥 | 创建 EPay 兼容密钥时显示的 EPay Key |
   | 支付处理路由 | `/pay/yipay` |
   | 是否启用 | 是 |

3. 微信同理，编辑「易支付-微信」，支付标识 `wxpay`，其余相同。

独角数卡的字段名容易填反：**商户 KEY 填网关地址，商户密钥才是 EPay Key**。
