# CoAI（原 ChatNio）× KPay

CoAI 后台自带「易支付」，直接填 KPay 的参数就能用，不用装插件。

> CoAI 的支付后端没有包含在开源仓库里，下面按它后台界面上的字段编写。

## 开始前

按 [KPay 准备](../kpay-setup.md) 拿到商户ID和 EPay Key。创建 EPay 密钥时，**授权域名**填 CoAI 的**后端域名**和前端访问域名（两者不同的都加进去）。

## 配置

1. 管理员进入 **系统设置 → 常规设置**，确认已填写 **后端域名**（易支付的异步通知要靠它）。
2. **系统设置 → 支付设置 → 易支付**：

   | 字段 | 填什么 |
   |---|---|
   | 启用易支付 | 打开 |
   | 易支付域名 | `https://api.kaipay.cn` |
   | 商户 ID | KPay「EPay 接入 → EPay 配置」里的商户 ID |
   | 商户密钥 | 创建 EPay 兼容密钥时显示的 EPay Key |
   | 支付方式 | 勾选支付宝、微信支付（QQ 等其他方式 KPay 不支持） |
   | 聚合支付模式 | 可以打开：用户点支付后直接进 KPay 收银台，在那里选支付宝或微信 |

3. 保存。

## 测试

用普通用户购买一笔小额点数或订阅，付款后到账即可。
