# OneHub × KPay

OneHub 自带易支付，直接填 KPay 的参数就能用，不用装插件。

## 开始前

按 [KPay 准备](../kpay-setup.md) 拿到商户ID和 EPay Key。创建 EPay 密钥时，**授权域名**填 OneHub 的访问域名（支付设置里另外填了回调域名的，填那个域名）。

## 配置

1. 管理员登录，打开 **支付设置 → 支付**（地址 `/panel/payment`），点 **新建**。
2. 类型选 **易支付**，填写：

   | 字段 | 填什么 |
   |---|---|
   | 支付域名 | `https://api.kaipay.cn`（结尾不要带 /，OneHub 会自己拼 `/submit.php`） |
   | 商户号 | KPay「EPay 接入 → EPay 配置」里的商户 ID |
   | 密钥 | 创建 EPay 兼容密钥时显示的 EPay Key |
   | 支付类型 | 「收银台」由付款人在 KPay 页面选；也可以固定支付宝或微信。QQ、当面付等其他选项 KPay 不支持 |
   | 币种 | 人民币 |

3. 保存并启用。

## 测试

用普通用户在充值页充一笔小额，付款后余额自动增加即可。
