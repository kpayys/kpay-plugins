# 苹果CMS（MacCMS v10）× KPay

苹果CMS v10 自带「易支付」在线支付（会员积分充值），直接填 KPay 的参数就能用，不用装插件。

## 开始前

按 [KPay 准备](../kpay-setup.md) 拿到商户ID和 EPay Key。创建 EPay 密钥时，**授权域名**填苹果CMS 的访问域名（苹果CMS 用当前访问的域名生成回调地址，有多个域名的都加进去）。

## 配置

1. 后台 **系统 → 在线支付配置**。
2. 按需设置最小充值金额、兑换比例（1 元兑换多少积分）。
3. **易支付设置**：

   | 字段 | 填什么 |
   |---|---|
   | 接口地址 | `https://api.kaipay.cn/`（**结尾必须带 /**，苹果CMS 会直接拼 `submit.php`） |
   | 商户号 | KPay「EPay 接入 → EPay 配置」里的商户 ID |
   | 密钥 | 创建 EPay 兼容密钥时显示的 EPay Key |

4. 保存。

## 说明

- 回调地址是 `https://你的域名/index.php/payment/notify/pay_type/epay`，自动生成，确保它能被外网访问、伪静态规则没有拦截。
- 用户选「QQ 钱包」时 KPay 不支持，会打开 KPay 收银台让用户改选支付宝或微信。

## 测试

前台登录一个会员，在会员中心充值一笔小额，付款后积分自动到账即可。
