# 第一步：在 KPay 准备商户ID和密钥

不管对接哪个系统，都要先在 KPay 拿到两样东西：**商户ID** 和 **EPay Key（商户密钥）**。整个过程大约 10 分钟，其中域名验证要等 KPay 自动复查。

KPay 商户后台：<https://app.kaipay.cn>

## 1. 开通收款

注册 KPay 账号，完成商户入驻，确认账户已经开通收款（能在后台看到可用的支付方式）。没开通收款时，下单会失败。

## 2. 创建 EPay 兼容密钥

1. 打开左侧菜单 **API 密钥**，点 **创建**，类型选 **EPay 兼容 API**。
2. **授权域名**：填你网站的域名，一行一个，比如

   ```
   shop.example.com
   ```

   要填哪个域名：**接收支付通知的那个网站的域名**。KPay 只接受落在授权域名下的通知地址和跳转地址，填错了下单会提示「回调地址校验失败」。不确定时，就填用户访问你网站时浏览器地址栏里的域名；一个密钥可以填多个域名，也支持 `*.example.com` 这样的通配。
3. **IP 白名单**：可以不填。填了之后，只有这些 IP 发起的请求才被接受；用「浏览器表单提交」方式下单时请求来自付款人的网络，会被拦下，所以设了 IP 白名单就要用服务端下单。
4. 保存后页面会**只显示一次** EPay Key，马上复制保存好。丢了只能点 **重置 EPay Key** 重新生成，旧的会立即失效。

## 3. 完成域名验证

保存后，每个授权域名都要证明是你的，二选一：

| 方式 | 怎么做 |
|---|---|
| 网站文件 | 按页面提示，在网站根目录放一个 `kpay-domain-verification.txt`，保证 `https://你的域名/kpay-domain-verification.txt` 能打开，内容和页面上给的一致 |
| DNS 解析 | 按页面提示，给域名加一条 TXT 记录，主机记录 `_kpay-verify` |

放好后点验证，或等 KPay 自动复查。验证通过后，KPay 还会对域名做一次合规巡查，**状态显示「已通过」之前不能下单**。

## 4. 查看商户ID

打开左侧菜单 **EPay 接入 → EPay 配置**，页面上的 **商户 ID (pid)** 就是商户ID，是一串数字。

同一页还能设置：

- **响应模式**：默认「收银台」，付款人跳到 KPay 收银台完成支付，适合大多数场景，一般不用改。
- **自动补单**：通知没送达时 KPay 会自动重发。

## 5. 接口地址

所有插件和系统的「接口地址 / 网关地址」都填

```
https://api.kaipay.cn/
```

个别系统要求不带结尾的 `/` 或者要写完整的 `submit.php` 地址，各自的说明里会写明。

---

到这里你手上应该有：

- 商户ID：`1001` 这样的一串数字
- EPay Key：一长串字母数字
- 已验证通过的授权域名

下一步回到[总览](../README.md)，找到你用的系统，按对应说明配置。

## 可选：退款用的 API Key

EPay 协议本身没有退款接口。想在你的系统后台直接点退款（WHMCS、WooCommerce、超级支付、智简魔方、彩虹易支付插件都支持），需要再建一把「平台 API」密钥：

1. **API 密钥 → 创建**，类型选 **平台 API**（不是 EPay 兼容 API）。
2. 授权域名同样填你的网站域名并完成验证。
3. 接口权限勾选 **发起退款**。
4. 保存后记下 **API Key** 和只显示一次的 **API Secret**，填到插件的「退款 API Key / Secret」里。

不配置也没关系，退款可以直接在 KPay 商户后台操作。

## 服务商：进件用的 API Key

用彩虹易支付服务商模块给下级商户进件时，需要服务商身份的 API Key：在服务商账号的 **API 密钥** 页创建「平台 API」密钥，接口权限勾选：创建进件单、查询进件单、上传进件材料、查询旗下商户、查询分润流水、查询费率调整、提交费率调整、查看旗下商户投诉；授权域名填易支付站点的域名并完成验证。详见 [彩虹易支付说明](../epay/README.md#服务商模式)。
