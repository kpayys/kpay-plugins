# 异次元发卡 × KPay

在异次元发卡（acg-faka）里用 KPay 收款：商品下单、余额充值都能用，支持支付宝、微信支付、云闪付。

- 适用版本：异次元发卡 3.x（3.5.9 起的「多套支付配置」也支持）
- 安装包：`kpay-acg-faka.zip`

## 开始前

先按 [KPay 准备](../docs/kpay-setup.md) 拿到商户ID和 EPay Key。创建 EPay 密钥时，**授权域名**填异次元发卡的域名：后台 **系统设置 → 其他设置** 里填了「自定义支付回调域名」的，填这个域名；没填的，填用户访问你店铺时的域名。

## 1. 上传插件

把压缩包里的 `KPay` 文件夹上传到网站的 `app/Pay/` 目录：

```
你的网站根目录/
└── app/
    └── Pay/
        └── KPay/          ← 文件夹名必须是 KPay
            ├── Config/
            └── Impl/
```

## 2. 填写配置

后台 **支付插件**，找到 **KPay 凯付**，点 **配置**：

| 配置项 | 填什么 |
|---|---|
| 接口地址 | `https://api.kaipay.cn`（默认已填，不用改） |
| 商户ID | KPay「EPay 接入 → EPay 配置」里的商户 ID |
| 商户密钥 | 创建 EPay 兼容密钥时显示的 EPay Key |
| 下单方式 | 默认「服务端下单后跳转」。服务器访问不了外网时改成「浏览器表单提交」；KPay 密钥设了 IP 白名单的话必须用服务端下单 |
| 订单标题 | 选填。付款页和付款人账单上显示的名称，`{tradeNo}` 会替换成订单号；留空显示「订单 + 订单号」 |

## 3. 添加支付接口

后台 **支付接口 → 添加**：

- 支付插件：选 **KPay 凯付**
- 通道编码：按要显示的付款方式填

  | 通道编码 | 效果 |
  |---|---|
  | `alipay` | 支付宝 |
  | `wxpay` | 微信支付 |
  | `unionpay` | 云闪付 |
  | `cashier` | 打开 KPay 收银台，付款人自己选 |

- 3.5.9 及以后版本还要选 **支付配置**（就是第 2 步保存的那套）

想同时显示支付宝和微信，就添加两个支付接口，通道编码分别填 `alipay` 和 `wxpay`。

## 4. 测试

在支付接口列表点 **拨测**，能打开付款页就说明配置正确（拨测单不会真的发货）。然后前台买一个便宜的商品，付款后确认订单自动发货。

## 回调是怎么处理的

回调地址由异次元发卡自动生成（`/user/api/order/callback.订单号`），不用填写。插件会校验签名、商户ID和金额，三项都对上才会发货；KPay 会重试没有收到 `success` 的通知。

## 常见问题

**下单提示「回调地址校验失败」**
EPay 密钥的授权域名里没有异次元发卡的回调域名。到 KPay「API 密钥」编辑这把密钥，加上域名并完成验证。

**付款了但没发货**
到后台 **支付插件 → KPay 凯付 → 日志** 看有没有收到通知、失败原因是什么；同时在 KPay 订单详情里看通知记录。常见原因是站点开了 CDN 或防火墙，拦掉了 KPay 的通知请求。

更多问题见 [常见问题](../docs/faq.md)。

## 升级和卸载

- 升级：用新版的 `KPay` 文件夹覆盖旧的，配置保留。
- 卸载：先删除用到它的支付接口，再删掉 `app/Pay/KPay` 文件夹。
